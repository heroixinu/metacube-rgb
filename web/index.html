为什么部分功能不可写？

从 Windows 程序中能辨认出 GPU 混合/独显模式、Fn Lock、触摸板锁、键盘 RGB、CPU 功耗等 WMI 功能编号，但这不代表这台 MetaCube 实际搭载对应硬件，或者在 PVE 上安全可写。Web 版保留这些功能的能力检测与状态展示，待逐项验证后才能扩展写入。
